# 山东金德利餐饮集团有限公司 第二次拜访纪要

## 本次目标

细化门店运营场景，确认从总部视角、督导视角、门店视角分别最痛的协同问题，并评估试点门店的接受度。

## 明确的关键场景

1. 总部下发巡检要求后，门店反馈格式不统一
2. 督导发现问题后，整改责任人与完成时限缺少统一记录
3. 门店店长在手机上反馈问题时，希望尽可能少填字段
4. 总部想按区域看问题聚合，而不是逐店翻消息记录

## 客户关注点

- 移动端体验是否足够简单
- 是否支持门店拍照上传、整改前后对比
- 是否能对区域督导和门店店长做差异化权限
- 是否能在试点阶段快速看到“整改效率提升”的效果

## 主要异议

- 区域督导担心若字段过多，一线执行会敷衍
- 门店店长担心重复录入，与现有内部群沟通方式冲突
- 客户希望避免“大系统改造”印象，更偏向轻量试点

## 风险信号

- 如果第一阶段不能缩短总部到门店的反馈周期，客户会认为价值不明显
- 如果不能快速形成门店端使用示例，项目会被视为“总部视角工具”

## 本次结论

- 客户倾向从巡检、整改、反馈闭环三个场景切入
- 试点阶段不要求覆盖全部门店场景，但必须形成总部看板
- 移动端交互、照片上传、整改时限提醒，是客户判断试点价值的关键点

## 下一步承诺

- 客户两周内提供 20 家试点门店清单
- 运营总监参与试点流程共创
- 我方准备试点版门店操作演示

## 销售判断

客户意愿较高，但落地成功的关键不在功能数量，而在“让一线愿意用”。后续建议重点围绕试点门店体验、督导效率和总部可视化三条价值线展开。
