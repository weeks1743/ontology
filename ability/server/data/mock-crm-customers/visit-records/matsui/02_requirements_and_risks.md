# 上海松井机械有限公司 第二次拜访纪要

## 会谈目标

在首次拜访后，本次会议重点是把需求从“方向性问题”细化为具体业务场景，尤其关注跨工厂协同、售后服务流程、权限模型与系统集成边界。

## 本次明确的业务场景

1. 总部下达事项后，工厂执行状态无法实时汇总
2. 售后服务工单由邮件和线下电话协同，缺少统一记录
3. 设备维护计划、售后响应、客户投诉信息彼此割裂
4. 审批流转涉及多角色，但当前缺少清晰的权限边界

## 客户关注点

- 关注项目实施周期和跨系统集成成本
- 关注权限模型是否能满足总部审计要求
- 关注未来能否对接 ERP、OA 和设备管理相关系统
- 关注试点是否能先在单一工厂或单一业务流程切入

## 主要异议

- 预算需要总部批准，目前还没有完全锁定
- 客户提到竞品已经在强调“更短实施周期”和“行业模板”
- 客户担心如果一开始就做太多流程梳理，项目周期会失控

## 风险信号

- 若试点周期超过 2 个月，项目优先级可能下降
- 若不能给出清晰的权限设计说明，总部审核通过概率会降低
- 若无法明确第一阶段集成边界，信息化经理不愿进入立项评审

## 竞品信息

- 客户已经接触过一家强调“制造业模板化交付”的供应商
- 竞品优势在于交付周期短，但客户认为其权限深度和审计能力偏弱

## 下一步承诺

- 客户两周内给出试点范围和关键接口清单
- 客户希望我们准备一页纸的权限架构说明
- 销售和售前需联合输出“试点阶段与二期扩展”的边界划分

## 销售判断

客户从兴趣阶段进入了真实评估阶段。项目可推进，但必须避免“大而全”叙事。当前最关键的是：

- 把试点范围压缩到可控边界
- 明确权限与审计方案
- 用“可扩展但首期轻量”的方式回应竞品的实施速度压力
