# 如何添加新的外部技能

## 技能加载机制说明

系统目前使用**双轨加载机制**：

### 1. 新系统（skill-core，推荐）
- **加载路径**：`skills/external/<skill-name>/SKILL.md`
- **加载时机**：服务器启动时调用 `initSkillCore()` (server.ts:36)
- **存储方式**：内存注册表（skillRegistry Map），不写入数据库
- **优势**：
  - 100% 兼容 Claude Code SKILL 规范
  - 只需要 `SKILL.md` 文件，无需 `_meta.json`
  - 支持热重载：`POST /api/v2/skills/reload`
  - 支持 README.zh-CN.md 中文文档优先显示

### 2. 旧系统（external-skills.ts，已废弃）
- **加载路径**：`skills/external/<skill-name>/_meta.json` + `SKILL.md`
- **加载时机**：服务器启动时调用 `loadExternalSkills()` (server.ts:32)
- **存储方式**：写入 SQLite 数据库
- **问题**：
  - 需要 `_meta.json` 文件（大部分技能都没有）
  - ID 格式混乱（ext.xxx vs xxx）
  - 已不再使用，仅保留兼容性

### 3. API 路由合并逻辑
`GET /api/skills` (skills.ts:28) 会合并两个数据源：
1. 从 SQLite 获取旧系统技能
2. 从 skill-core registry 获取新系统技能
3. 去重合并（skill-core 优先）

## 添加新技能步骤（推荐方式）

### 步骤 1：创建技能目录结构

```bash
skills/external/<your-skill-name>/
├── SKILL.md           # 必需：技能定义文件
├── README.md          # 推荐：英文文档
├── README.zh-CN.md    # 推荐：中文文档（优先显示）
└── scripts/           # 可选：执行脚本目录
    └── main.py        # 或 main.js
```

### 步骤 2：编写 SKILL.md 文件

参考模板：

```markdown
---
name: <your-skill-name>
description: 技能简短描述（会显示在技能市场卡片上）
version: "1.0.0"
user-invocable: true
metadata:
  emoji: "🚀"
  category: "tool"
  tags: ["automation", "productivity"]
  openclaw:
    requires:
      bins: ["python3"]  # 或 ["node"]
      env: ["API_KEY"]   # 需要的环境变量
---

# 技能名称

详细描述技能的功能、使用场景和注意事项。

## 使用方法

说明如何使用该技能，包括参数说明。

## 示例

提供具体的使用示例。
```

**重要字段说明**：

- `name`: 技能 ID，建议使用 `xxx-yyy` 格式（不带 `ext.` 前缀）
- `description`: 会显示在前端技能卡片上
- `user-invocable`: 是否可被用户直接调用
- `metadata.emoji`: 技能图标，会显示在卡片上
- `metadata.openclaw.requires`: 执行依赖（可选）

### 步骤 3：更新 skill-names.json（可选）

在 `server/config/skill-names.json` 中添加显示名称映射：

```json
{
  "your-skill-name": {
    "display_name": "技能中文名",
    "emoji": "🚀",
    "github_path": "your-skill-name"
  }
}
```

### 步骤 4：重启服务器

```bash
npm run dev
```

服务器启动时会自动扫描 `skills/external/` 目录并加载技能。

### 步骤 5：验证加载

访问前端技能市场页面，应该能看到新技能卡片。

点击技能卡片会显示：
1. 优先显示 `README.zh-CN.md`（如果存在）
2. 其次显示 `README.md`
3. 最后显示 `SKILL.md` 的 body 部分

## 热重载技能（无需重启）

调用 API 重新扫描技能目录：

```bash
curl -X POST http://localhost:3002/api/v2/skills/reload
```

响应示例：
```json
{
  "reloaded": 3,
  "skills": ["baidu-search", "kai-report-creator", "volcengine-web-search"]
}
```

## 常见问题

### Q: 为什么我的技能没有显示？
A: 检查以下几点：
1. `SKILL.md` 文件是否存在
2. frontmatter 格式是否正确（`name` 和 `description` 字段必需）
3. 查看服务器启动日志：`[skill-core] Loaded X skills`

### Q: 技能 ID 格式应该是什么？
A: 使用 `xxx-yyy` 格式，不要带 `ext.` 前缀。例如：
- `kai-report-creator` ✓
- `ext.kai_report_creator` ✗（已废弃）

### Q: 需要创建 `_meta.json` 吗？
A: 不需要。新系统只需要 `SKILL.md` 文件。

### Q: 如何设置技能显示名称和图标？
A: 在 `SKILL.md` 的 `metadata` 中设置 `emoji`，或在 `skill-names.json` 中配置 `display_name` 和 `emoji`。

### Q: 技能详情显示什么内容？
A: 按以下优先级：
1. `README.zh-CN.md`（中文文档）
2. `README.md`（英文文档）
3. `SKILL.md` body 部分

## 调试技巧

### 查看已加载技能
```bash
curl http://localhost:3002/api/v2/skills
```

### 查看单个技能详情
```bash
curl http://localhost:3002/api/v2/skills/<skill-id>
```

### 查看前端合并后的技能列表
```bash
curl http://localhost:3002/api/skills
```

### 检查数据库记录
```bash
sqlite3 server/data/ability.db "SELECT id, name, category FROM skills WHERE category='external';"
```

注意：数据库中可能没有新系统技能的记录，这是正常的。

## 总结

添加新技能只需要：
1. 在 `skills/external/` 下创建目录
2. 编写 `SKILL.md` 文件（必需）
3. 编写 `README.zh-CN.md`（推荐）
4. 重启服务器或调用热重载 API

无需：
- 创建 `_meta.json`
- 手动插入数据库
- 添加额外配置文件
