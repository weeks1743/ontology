## UI 设计特点

### 深空暗色主题
- 背景色：`#0a0f1e` (space-darker)
- 玻璃效果：`rgba(15, 23, 42, 0.6)` + `backdrop-blur(12px)`
- 边框：`rgba(100, 200, 255, 0.1)`

### 状态指示
- ✅ 通过：绿色 `text-green-400`
- ❌ 失败：红色 `text-red-400`
- ⏳ 运行中：蓝色 + 旋转动画
- ⚠️ 待测试：灰色 `text-gray-400`

### 交互反馈
- 按钮悬停效果
- 加载状态禁用
- 模态对话框遮罩
- 卡片悬停边框高亮

## 使用流程

### 配置外部技能
1. 访问技能市场 → 外部技能 Tab
2. 点击技能卡片上的 ⚙️ 配置按钮
3. 在对话框中输入配置信息（如 API Key）
4. 点击保存

### 运行测试用例
1. 访问技能测试页面
2. 选择本体技能或外部技能 Tab
3. 点击单个测试的"运行"按钮，或点击"运行全部测试"
4. 查看测试结果和统计信息
5. 展开查看详细的参数和结果

### 执行技能
1. 访问技能市场
2. 点击技能卡片或"试用"按钮
3. 进入技能详情页
4. 输入 JSON 参数
5. 点击"执行技能"
6. 查看执行结果和数据库状态

## 技术实现

### 组件通信
- Zustand 全局状态管理
- Props 传递回调函数
- React Router 路由导航

### API 集成
- `/api/skills` - 技能列表
- `/api/skills/:id/execute` - 执行技能
- `/api/external-skills/config/:skillId` - 技能配置
- `/api/logs` - 执行日志

### 状态管理
```typescript
interface TestCase {
  id: string;
  name: string;
  description: string;
  skillId: string;
  params: any;
  status: 'pending' | 'running' | 'passed' | 'failed';
  actualResult?: any;
  error?: string;
  duration?: number;
}
```
